# M2 quality and model-candidate checks — 19 September 2026

M2 remains unaccepted. Runtime completion, lexical/range validation and manual content acceptance are separate gates. No M3 tools, model downloads, deployment changes or model-executed repository commands were introduced.

## Implemented changes

- Allow one evidence reminder after denied reads, while retaining the original scope. Out-of-scope reads return `SCOPE_PATH_UNAVAILABLE` without checking whether the path exists. They must not be described as missing files.
- Require list cursors to be empty or previously issued in this attempt. Schema-batch repair and all recovery still consume the existing budgets.
- Recognize Unicode/space/extensionless quoted citation paths and common quoted-path line suffixes. Reject unknown paths, gaps and ranges beyond observed lines.
- Check inline backtick literals against filtered observed source, decoded JSON string values and known paths. Handle read line labels and source-property token boundaries. One shared revision can repair literals and citations; persistent failures return bounded codes.
- Permit host selection of three already-installed candidates: `qwen3:8b`, `gpt-oss:20b`, `qwen3.5:latest`. Default remains Qwen 3 8B, 8192 context and 512 output tokens. No automatic fallback. GPT-OSS uses low reasoning; reasoning text is discarded.
- Clarify final-answer guidance: concise findings with citations, exact inline literals, decode command escapes once, distinguish imported calls from their unseen implementations and explicit error branches from propagated errors. Do not claim a check ran merely because its implementation was read.

The literal check is deliberately limited. It can reject legitimate paraphrases and does not cover every plain-prose identifier, fenced code block or semantic claim. Whitespace normalization is not semantic equivalence. Mentioning an unavailable path is permitted for reporting limitations, not evidence that its contents were seen. Failed-answer diagnostics record counts only, so failures below do not prove that every rejected statement was factually wrong.
